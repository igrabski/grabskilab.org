# Grabski Lab website

Private working repository for [grabskilab.org](https://grabskilab.org).

## Status

This is an unpublished first draft. Biographical text, research descriptions, recruitment details, contact information, and photography are placeholders unless linked to a published source.

## Preview

Open `index.html` in a browser. The site has no build step and no external JavaScript dependencies.

## Before launch

- Replace draft research and biography text.
- Add a real headshot and, if desired, scientific imagery.
- Confirm appointments and institutional naming.
- Add an email address, location, and application instructions.
- Review publication details and add final links.
- Configure `grabskilab.org` only after the content is approved.
